# Native bridge (placeholder — M4+)

Swift (or Objective-C) helper for **EventKit**, menu bar, and other macOS APIs that Python cannot access cleanly.

- IPC with `services/core` (HTTP localhost or Unix socket) TBD during M4.
- Not required for **M0–M1**.

See [`docs/spec/architecture.md`](../docs/spec/architecture.md) and [`docs/spec/milestones.md`](../docs/spec/milestones.md).
